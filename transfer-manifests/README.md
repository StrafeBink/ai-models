# AI Box Transfer Manifests

Dated transfer manifests generated by `scripts/generate_ai_box_transfer_manifest.py` can be saved here when a manual AI-box copy batch is planned or completed.

Generated example:

```bash
python scripts/generate_ai_box_transfer_manifest.py --bundle minimal-rag --dest-root /path/on/ai-box/models
```

Commit manifests that represent real planned/completed transfer batches; discard throwaway examples.
